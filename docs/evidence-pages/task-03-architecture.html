2Layered application architecture

PRESENTATION
Thymeleaf templates + app.css — layout.html, login, offers list / form / detail, dashboard. No JS framework, no CDN asset (NFR-06).
WEB
Spring MVC controllers — OfferController, DashboardController, LoginController, GlobalModelAdvice, GlobalExceptionHandler.
SECURITY
Spring Security filter chain — form login, BCrypt hashes, CSRF tokens, ROLE_AGENT / ROLE_MANAGER / ROLE_ADMIN.
SERVICE
OfferService (use cases) and OfferWorkflow (state rules) — the only place a status transition may be decided.
PERSISTENCE
Spring Data JPA — RetentionOfferRepository with the combined search query.
DATABASE
H2 file database at ./data/retention.mv.db — survives container restarts, which the Task 14 rollback demo relies on.
Key architectural rule. A controller never changes a status directly — it calls OfferWorkflow. That single choke point is what makes success criterion SC1 ("zero offers sent without approval") testable without a browser.

FrameworkSpring Boot 3.5.6Web, security, JPA, validation and health in one dependency set
