4Definition of Ready

  • Story in role–goal–benefit form
  • Acceptance criteria written and testable
  • Estimated in story points
  • Dependencies identified and unblocked
  • Traces to an MVP item M1–M15

5Definition of Done — 15 checks

  • Code — meets all acceptance criteria
  • Written on a feature/* branch only
  • Commits follow type(scope): subject
  • No dead code, debug prints or secrets
  • Review — PR raised with review comments
  • Merged to develop, conflicts resolved
  • Build — mvn clean package passes locally
  • Unit tests pass; workflow rules explicitly tested
  • Jenkins build for the merge commit is SUCCESS
  • Selenium regression suite green
  • Deploy — artefact archived by Jenkins
  • Deployed by pipeline, no manual steps
  • Health check on deployed URL returns 200
  • Docs — task document updated
  • Screenshot evidence captured
